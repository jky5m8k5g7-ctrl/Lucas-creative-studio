# Full craft briefs (reference)

These are the long-form craft briefs, one per department, written and then revised three
times against a practitioner critic who scored each 1–10 and listed what was generic, wrong or
missing. None reached the critic's bar of 8: every one finished at 7, and the critic's last round
still found real corrections (listed per role in the run's output). Treat them as reference
material, not as verified fact.

The studio's agents don't read these. They read the condensed working briefs one level up
(`spec/roles/<role>.md`, about 6 KB each), because long rulebooks dilute an agent's attention
and make reviewers grade against trivia; the 4 KB copywriter brief is the one with a measured
effect (see `tests/results/`). The full versions are here for the later enhancement phase and
for anyone improving a working brief.
